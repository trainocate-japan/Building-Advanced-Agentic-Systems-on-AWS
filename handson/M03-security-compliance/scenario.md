# モジュール 3: セキュリティとコンプライアンスの実装 - ハンズオンシナリオ

## シナリオ概要

あなたは金融サービス企業のセキュリティアーキテクトです。顧客対応用のマルチエージェントシステムを本番環境にデプロイする前に、包括的なセキュリティ対策を実装する必要があります。エージェントが自律的にアクションを実行するため、従来のアプリケーション以上に厳格なセキュリティ制御が求められます。

AgentCore の Identity、Policy、Guardrails を活用して、多層防御のセキュリティアーキテクチャを構築します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります：

1. **AgentCore Identity の設定**: エージェントの認証と認可を設定する
2. **AgentCore Policy（Cedar）**: 細粒度のアクセス制御ポリシーを実装する
3. **Bedrock Guardrails**: コンテンツフィルタリングとPII保護を設定する
4. **監査ログ**: 包括的な監査証跡を実装する
5. **多層防御**: エージェンティック AI に適したセキュリティアーキテクチャを理解する

## エージェンティック AI のセキュリティスコーピングマトリックス

| ディメンション | 説明 | 実装手段 |
|-------------|------|---------|
| アイデンティティ (AuthN/AuthZ) | 誰がエージェントを呼び出せるか | AgentCore Identity |
| エージェンシーの境界 | エージェントが何をできるか | AgentCore Policy (Cedar) |
| データ保護 | PII・機密情報の保護 | Guardrails |
| 監査とログ記録 | 何が起きたかの記録 | CloudTrail / CloudWatch |
| オーケストレーション | エージェント間通信のセキュリティ | Gateway + IAM |

## OWASP エージェンティック AI 脅威

- ランタイムの予期しない動作
- 権限の逸脱
- ビジネスルールの誤解釈
- データエクスポージャー

## 使用する AWS サービス

- Amazon Bedrock AgentCore Identity
- Amazon Bedrock AgentCore Policy（Cedar）
- Amazon Bedrock Guardrails
- AWS CloudTrail
- Amazon CloudWatch Logs
- AWS IAM
